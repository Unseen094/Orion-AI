Orion is an open-source AI operating system built around **Yards** — task-specific workspaces that open automatically based on what you ask.

> **Ask. Orion decides. The right workspace opens.**

## ✦ Features

* ◉ **AI Orb** — Idle, Listening, Thinking and Executing states
* 💻 **Coding Yard** — Monaco, file explorer and AI code generation
* 🔎 **Research Yard** — Search, summaries and notes
* 🖱️ **Computer Control** — Mouse and keyboard automation
* 🔑 **BYOK** — Use your own Gemini API key
* 🔌 **MCP-ready** — Extensible tool architecture
* 📴 **Offline Mode** — Seeded data and fallback responses

## 📦 Run

```powershell
git clone https://github.com/YOUR_USERNAME/orion.git
cd orion
.\scripts\dev.ps1
```

Configure your Gemini API key from:

`Settings → API Key`
